1. Getting Started

  1. Open the Automated Smart ECM web application in your browser.
  2. Click Sign in and enter your Windows account credentials.
  3. After login, use the left function panel to switch modules.
  4. Your available modules depend on your assigned role.

2. Function Panel Navigation

  • My Dashboard: Personal tasks and reminders overview.
  • Document Management: Folder/document operations, approvals, uploads, versions.
  • Knowledge Collaboration: Topic-based collaboration linked to documents.
  • System Administration: Retention, reminders, job schedules, code tables.
  • User Management: Users, groups, and role assignments (admin only).
  • System Auditing: Audit trail search and review.
  • Reports: Generate and review reports.

3. Document Management

3.1 Folder operations

  • Use the folder browser on the left side of the workspace. Select a folder to filter the document list to that folder.
  • Use New folder to create a root folder, or select a parent first and choose Nest inside selected folder.
  • Use Edit folder to rename a folder, move it to another parent, or change its metadata template.
  • Use Delete folder only when the folder has no documents and no child folders.
  • Only folders for which you have effective Read, Write, or Delete access appear in the folder tree.

3.2 Document operations

  • Upload new documents to a folder where you have Write access.
  • Select a document to open its details, metadata, approval status, version history, and preview.
  • Use Upload new version to preserve the document identity while adding a revised file.
  • Use Download from the details or version history to retrieve the latest or a specific version.
  • Use Archive to remove a document from active work while retaining its history.

3.3 Sorting and filtering

  • Use keyword, owner, category, status, and tag filters.
  • Apply sorting options in the document list.

4. Folder Operations in Detail

4.1 Create a root folder

  1. Open Document Management and select the folder browser's New folder button.
  2. Enter a folder name and leave Nest inside selected folder unchecked.
  3. Optionally add metadata fields. Each field needs a unique key, a label, a type, and a required setting.
  4. Administrators can assign Read, Write, and Delete permissions for each user group.
  5. Select Create folder. The new folder appears in the tree.

4.2 Create a child folder

  1. Select the intended parent folder before opening New folder.
  2. Check Nest inside selected folder.
  3. Check Metadata template inherit from parent folder if the child should follow future parent template changes.
  4. Check Folder permissions inherit from parent folder if the child should follow future parent permission changes.
  5. Inherited metadata and permissions are displayed for review and are locked while inheritance is enabled.
  6. Save the folder. Uncheck an inheritance option later in Edit folder to make that aspect independent and editable.

4.3 Folder permissions

  • Read: allows a user group to see and open content in the folder.
  • Write: allows document uploads, updates, moves, and metadata changes permitted by the workflow.
  • Delete: allows destructive document or folder actions where the operation is otherwise valid.
  • When a parent permission matrix changes, children marked as inherited receive the same group permissions recursively.
  • Children that are not inherited keep their own permission matrix.
  • Folder permission administration is available to authorized system or user administrators.

4.4 Metadata templates

  • A folder metadata template defines fields that uploaders must complete, such as dropdowns, dates, text, or numeric values.
  • Use a stable, unique field key because documents use that key to store values.
  • When template inheritance is enabled, adding, removing, or changing a parent field updates inherited descendants.
  • Uncheck inheritance in the child folder editor before adding child-specific fields.

5. Document Operations in Detail

5.1 Upload a document

  1. Select a destination folder where you have Write access and choose Upload.
  2. Select the file. PDF files can optionally run OCR, data extraction, or embedding after upload.
  3. Complete the title, description, document date, and comma-separated tags. Tags are normalized automatically.
  4. Complete every required field shown by the folder metadata template. Dropdown values may come from a configured code table.
  5. Select reviewer, approver, or supervisor values when the workflow requires them.
  6. Submit the upload and wait for the success notification. Background OCR or embedding may continue after the dialog closes.

5.2 Search and filter

  • Use Filter keywords above the document list for a quick search.
  • Use the filter controls for owner, category, status, tags, dates, document metadata, folder name, and folder metadata.
  • Use the folder tree to scope results to one folder. Clear the folder selection to search all accessible folders.
  • Use the sort menu to order by newest, oldest, title, size, or status.
  • Search results respect your effective folder permissions.

5.3 Edit metadata and versions

  • Open a document and choose Edit in the Metadata section when you have Write access.
  • Update title, description, category, tags, document date, or custom metadata, then save.
  • Use the Versions section to review file names, sizes, upload times, and historical versions.
  • Upload a new version instead of creating a duplicate document when the file represents a revision of the same record.

5.4 Approval and archive

  • Review approval history, assigned reviewer/approver, requested time, and decision status in the Approval section.
  • Approvers may approve or reject according to the workflow and may add notes or delegate where permitted.
  • Archived documents are retained for history but are removed from normal active work lists.
  • Restore or permanent deletion actions, when available, require the appropriate permission and role.

6. Knowledge Collaboration

  1. Create a topic with title, description, and tags.
  2. Join the topic to enable update/contribution/share/link/upload actions.
  3. Add contributions and optionally link related documents.
  4. Share a topic with users and upload supporting files.
  5. Download the knowledge chain for topic history export.

Tip: When entering from document actions, the topic search can auto-focus based on document context.

7. My Dashboard

  • Review KPI tiles for workload and status.
  • Use the calendar view to inspect due items by day.
  • Track workflow tasks and reminders in dedicated lists.

8. System Administration

  • Retention Management: Configure retention rules and sweeps.
  • Reminder Management: Configure reminder offsets and trigger logic.
  • Job Management: Manage scheduled jobs and execution settings.
  • Code Table Management: Maintain reference data for business fields.

9. System Auditing and Reports

  • Use System Auditing for traceability of user and document actions.
  • Use Reports to generate operational and compliance outputs.

10. Operational Tips and Troubleshooting

  • If an action is unavailable, verify your role and folder permissions first.
  • If document/topic lists look stale, refresh the page and retry the operation.
  • When file upload fails, verify file type/size and your folder/topic permissions.
  • If login fails, confirm account credentials and account status with admin.
